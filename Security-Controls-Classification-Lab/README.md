# Security Controls Classification Lab

## Objective
Identify, classify, and analyze real-world security controls according to CompTIA Security+ security control categories and control types.

---

## Skills Demonstrated

- Security Controls Identification
- Defense in Depth Analysis
- Security Documentation
- Risk Awareness
- Physical Security Controls Analysis
- Application of Security+ Concepts

---

## Environment
This lab utilized observations from anonymized real-world commercial environments encountered during physical security operations. All site-specific information has been generalized to protect confidentiality.

---

## Methodology
1. Observe existing security controls.
2. Identify the security control category and control type.
3. Analyze how controls contribute to layered security.
4. Document findings and lessons learned.

---


## Generalized Security Control Analysis

The following table summarizes security controls examined during this learning exercise. It groups controls by their security functions rather than documenting configurations at individual properties or client facilities.

| Generalized Control | Category | Type |
|---|---|---|
| Perimeter Barriers | Physical | Preventive, Deterrent |
| Credential-Based Entry Controls | Physical | Preventive |
| Access Authorization Procedures | Operational | Preventive |
| Security Personnel and Patrols | Physical, Operational | Detective, Deterrent |
| Surveillance Systems | Physical | Detective |
| Security Lighting | Physical | Deterrent |
| Posted Access Instructions | Physical | Directive |

This classification illustrates how different control categories and types contribute to defense in depth. It is not a site-specific security inventory.

---

## Security+ Relevance

This lab reinforces CompTIA Security+ concepts related to security control categories, control types, and defense-in-depth principles by applying these concepts to real-world environments.

---

## Key Findings

- Security controls often serve multiple purposes.
- Multiple control categories and control types can exist simultaneously within a single environment.
- Physical security principles closely align with cybersecurity defense-in-depth concepts.
- Real-world environments commonly implement layered controls rather than relying on a single mechanism.

---

## Lessons Learned

- Developed a better understanding of how security controls are implemented in real-world environments.
- Improved ability to classify controls using cybersecurity terminology.
- Recognized how layered controls contribute to overall security posture.
- Identified how physical security operations experience connects to cybersecurity concepts such as defense in depth and risk assessment.
